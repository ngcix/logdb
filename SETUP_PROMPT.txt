Install logdb - A fast diagnostic log analyzer powered by DuckDB

## What You're Installing

- **logdb module**: Python CLI tool that imports logs (dumpstate, pcap, hci) into DuckDB for fast analysis
- **logdb-make skill**: Database creation and config management
- **logdb-query skill**: Log search, navigation, and analysis

## Installation Instructions

### 1. Install Python Module

Run this command in your terminal:

```
pip install https://github.sec.samsung.net/cuong-nguyen/logdb/releases/download/release/logdb-1.0.0-py3-none-any.whl
```

Or from source:
```
pip install git+https://github.sec.samsung.net/cuong-nguyen/logdb.git
```

### 2. Initialize Configuration

```
logdb config init
```

This creates configuration directory at `~/.logdb/config/` with defaults for all log types.

### 3. Add Skills to Your AI Provider

**For Claude Code (VSCode):**
- Create `.claude/skills/logdb-make/` and `.claude/skills/logdb-query/` directories in your project
- Download these files:
  - https://github.sec.samsung.net/cuong-nguyen/logdb/blob/main/.claude/skills/logdb-make/SKILL.md
  - https://github.sec.samsung.net/cuong-nguyen/logdb/blob/main/.claude/skills/logdb-query/SKILL.md
- Save each as `SKILL.md` in the respective directory

**For Claude.ai (Web):**
- Copy skill content from the URLs above
- Add to your personal skill library (if available)

**For Other Providers:**
- Check your provider's skill/tool documentation
- Skills may not be supported (use CLI directly instead)

### 4. Verify Setup

```
logdb config init
logdb --help
ls ~/.logdb/config/
```

## Usage Examples

**Create database from log:**
```
logdb make -i dumpstate.log -t dumpstate -o case.duckdb
```

**Search logs:**
```
logdb search case.duckdb -t dumpstate -c tag ERROR -r 50
```

**Edit configuration:**
```
logdb config open -t dumpstate
```

**Navigate logs:**
```
logdb next case.duckdb -t dumpstate -l 1000 -r 20
logdb previous case.duckdb -t dumpstate -l 1000 -r 20
```
