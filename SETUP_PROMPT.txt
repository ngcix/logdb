LOGDB SETUP PROMPT
Paste this whole block into your coding agent, or follow it by hand.
==============================================================================

Please set up logdb for me — a CLI that imports large diagnostic logs
(dumpstate, pcap, hci) into DuckDB so they can be searched in milliseconds.

------------------------------------------------------------------------------
STEP 1 — Install the module
------------------------------------------------------------------------------

pip install https://github.sec.samsung.net/cuong-nguyen/logdb/releases/download/release/logdb-1.0.0-py3-none-any.whl

Or from source:

pip install git+https://github.sec.samsung.net/cuong-nguyen/logdb.git

Always invoke it as a module — this works whether or not pip's scripts
directory is on PATH, and inside virtualenvs:

python -m logdb --help

------------------------------------------------------------------------------
STEP 2 — Generate the default configs
------------------------------------------------------------------------------

python -m logdb config init

This writes one config per log type to ~/.logdb/config/ and prints the path:

  ~/.logdb/config/dumpstate.toml
  ~/.logdb/config/pcap.toml
  ~/.logdb/config/hci.toml

Configs are shared by every database of that type, so parsing rules and
column lists are edited in exactly one place:

python -m logdb config open -t dumpstate

------------------------------------------------------------------------------
STEP 3 — Add the two usage guides
------------------------------------------------------------------------------

logdb ships two guide files. Download both and place them wherever this
tool loads its instruction/guide files from — the directory name differs
between tools, so use whatever location applies here:

  logdb-make   — create databases, manage configs
  https://github.sec.samsung.net/cuong-nguyen/logdb/raw/main/skills/logdb-make/SKILL.md

  logdb-query  — search, navigate, and analyze imported logs
  https://github.sec.samsung.net/cuong-nguyen/logdb/raw/main/skills/logdb-query/SKILL.md

Keep each file named SKILL.md inside its own folder (logdb-make/,
logdb-query/). If this tool has no such directory, just read the two files
as reference — every command they document works from the terminal.

------------------------------------------------------------------------------
STEP 4 — Verify
------------------------------------------------------------------------------

python -m logdb --help
python -m logdb config init
python -m logdb make -i <your-log-file> -t dumpstate -o case.duckdb
python -m logdb inspect case.duckdb

------------------------------------------------------------------------------
COMMAND REFERENCE
------------------------------------------------------------------------------

Create / configure
  python -m logdb make -i LOG -t {dumpstate|pcap|hci} -o DB [--force]
  python -m logdb config init [-t TYPE]
  python -m logdb config open -t TYPE

Search / analyze  (all output JSON)
  python -m logdb inspect DB
  python -m logdb search DB -t TABLE -c COLUMN REGEX [--from N] [--to N] [-r N]
  python -m logdb next DB -t TABLE -l LINE [-c COLUMN REGEX] [-r N]
  python -m logdb previous DB -t TABLE -l LINE [-c COLUMN REGEX] [-r N]
  python -m logdb query DB "SELECT ..." [-r N]

Examples
  python -m logdb make -i dumpstate.log -t dumpstate -o case.duckdb
  python -m logdb search case.duckdb -t dumpstate -c level E -r 50
  python -m logdb previous case.duckdb -t dumpstate -l 2523 -r 10
  python -m logdb query case.duckdb "SELECT line_no, tag, message FROM dumpstate WHERE tag LIKE '%Bluetooth%'"

Notes
  - Every table gets line_no (primary key) and raw_line automatically.
  - --force drops and rebuilds the table, for re-importing after a config edit.
  - pcap requires tshark on PATH (install Wireshark).
